Pagamenti - Lightbox

Lascia vuoto per usare lo script di default. Solo URL https. Con "Custom JS" incolli o carichi direttamente il codice: ha priorità sull’URL.

Dati pagamento

Codice esercente
ID transazione generato dal server
Token generato dal server
Scegli se gestire l’esito via JavaScript o lasciare il redirect automatico

Istruzioni

  1. Effettua la chiamata POST /payment/create dal tuo server
  2. Ricevi paymentID e paymentToken nella risposta
  3. Inserisci i dati nei campi sopra
  4. Clicca su "Apri Lightbox"
Esempio request body server
{
  "shopLogin": "GESPAY00001",
  "amount": 10.00,
  "currency": "EUR",
  "shopTransactionID": "FBK_OrderID_001"
}
